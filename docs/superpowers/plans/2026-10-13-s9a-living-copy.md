# S9a' — The living copy of the ELAN 3 applications — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `applications/` and `contributions/` at the root of the repository become living copies of `legacy/elan3/applications` and `legacy/elan3/contributions`, with plain `TESTS` files instead of the csh `tst_all` scripts, and the legacy bench runs them instead of `legacy/` — with exactly the same test statuses as before.

**Architecture:** A one-shot importer (`tests/apps/import_legacy.py`) copies the two trees without CVS and build products, resolves the Robot case collisions for good (`Nim`→`nim2`, `Robot`→`robot2`, `Space`→`space2`, `State`→`state2`, imports updated), converts each `tst_all` into a `TESTS` file and folds in the overlay pilot (`Features/toi_meme`). `run_tests.py` discovers `TESTS` files under the two trees (ids `applications/X::K::...`) and keeps the historical `tst_all` files of `legacy/elan/sources`; the overlay code goes. A one-shot migration (`tests/apps/migrate_ids.py`) renames every id-keyed record (baseline, fixes-2004, platform exceptions, snapshots, G/R expectations). The S9 tools move from `tests/legacy-overlay/` to `tests/apps/` and target the copy.

**Tech Stack:** Python 3 standard library (unittest), POSIX sh, GNU make.

**Spec:** `docs/superpowers/specs/2026-10-12-s9-legacy-apps-tests-design.md` §8 (the revision of 2026-10-13), with §3 and §5.

## Global Constraints

- `legacy/` is never modified; it stays the archive. The copy is `applications/` and `contributions/` at the repository root.
- Not copied: `CVS/`, `*.o`, `a.out`, `.elan.*/`, `.elan-go.*/`, `*.make`, `*.ref`. No `x-case-` file and no case collision in the copy (`make check-case`).
- Test file format, one test per line: `[long] <cmd> LGI SPC INP OUT [flags...]`, `cmd` in `itest` (I), `aitest` (A), `jtest` (J, JO, R, G; `jtest LGI SPC OUT [flags]`, no INP), `gtest` (G with INP); `#` starts a comment.
- Test ids of the copy: `<applications|contributions>/<path>::<kind>::<lgi>:<spc>:<inp or ->:<out>`; ids of `legacy/elan/sources`, `regression/`, `examples/` do not change.
- After the switch, the bench gives the same status for every migrated test as before it (0 regressions, 0 improvements, 0 snapshot differences, same counts per status), for I,A (modern), J,JO (modern), G (`bench_parity.py`), and against the reference (`make check-reference`).
- `make check` stays green at every commit; its duration does not grow.
- `tests/golden` and `tests/compiler-rs/test_ref_roundtrip.sh` keep reading `legacy/` (unchanged).
- Work on branch `s9-legacy-apps` in `~/github/elan-cs`; final check also in a clone on the default (case-insensitive) volume.
- Commit messages end with a `Co-Authored-By: Claude <model> <noreply@anthropic.com>` trailer naming the model that wrote the commit. No push, no merge without the controller.

#!/usr/bin/env python3
"""Make the living copy of the ELAN 3 applications (spec S9 §8), once:
legacy/elan3/applications -> applications/, legacy/elan3/contributions ->
contributions/, without CVS/ and build products; each tst_all (csh)
becomes a TESTS file (format: tests/apps/README.md); the overlay pilot of
tests/legacy-overlay/elan3/ is folded in; the Robot case collisions are
resolved for good (RENAMES). Refuses to overwrite an existing copy.
Usage: import_legacy.py"""
import re
import shutil
import sys
from pathlib import Path

HERE = Path(__file__).resolve().parent
REPO = HERE.parent.parent
sys.path.insert(0, str(REPO / "tests" / "legacy-bench"))
import run_tests as rt  # noqa: E402

IGNORE = shutil.ignore_patterns("CVS", "*.o", "a.out", ".elan.*", ".elan-go.*",
                                "*.make", "*.ref", "tst_all", "tst_all.overlay",
                                "tst_one", "PORTING.md")
# Robot: Nim.eln/nim.eln, Robot.lgi/robot.lgi... are two variants of a
# program; the capitalised one (stored as x-case-*, CASE-RENAMES.tsv) is
# renamed with a 2 (module, LPL and file names, imports, test lines).
ROBOT = Path("applications/Robot")
RENAMES = {"Nim": "nim2", "Robot": "robot2", "Space": "space2", "State": "state2"}
HEADER = "# tests of {name} (from legacy/elan3 tst_all; format: tests/apps/README.md)\n"


def tests_lines(tst_all, renames):
    """The test lines of a csh tst_all, in the TESTS format; renames apply
    to the LGI, INP and OUT fields."""
    lines = []
    for cmd, a, long_ in rt.parse_tst_all(tst_all):
        names = (0, 2) if cmd == "jtest" else (0, 2, 3)
        a = [renames.get(w, w) if i in names else w for i, w in enumerate(a)]
        lines.append(("long " if long_ else "") + " ".join([cmd, *a]))
    return lines


def parse_tests(path):
    """Yield (cmd, args, long) for each line of a TESTS file."""
    for raw in path.read_text(errors="replace").splitlines():
        words = raw.split("#", 1)[0].split()
        if not words:
            continue
        long_ = words[0] == "long"
        if long_:
            words = words[1:]
        if words and words[0] in rt.KIND_OF_CMD:
            yield words[0], words[1:], long_


def rename_robot(d):
    """In the copy of Robot (d): x-case-X.* -> x2.* (RENAMES), contents
    of the renamed files rewritten (module/LPL names, imports)."""
    word = re.compile(r"\b(" + "|".join(RENAMES) + r")\b")
    for p in sorted(d.rglob("x-case-*")):
        stem, _, ext = p.name[len("x-case-"):].partition(".")
        new = p.with_name(f"{RENAMES[stem]}.{ext}")
        p.rename(new)
        if ext in ("eln", "lgi"):
            new.write_text(word.sub(lambda m: RENAMES[m.group(1)], new.read_text()))


def import_tree(src, dst, overlay):
    if dst.exists():
        raise SystemExit(f"{dst} exists: the copy is made once")
    shutil.copytree(src, dst, symlinks=True, ignore=IGNORE)
    for tst in sorted(src.rglob("tst_all")):
        if tst.parent == src or "CVS" in tst.parts:
            continue
        rel = tst.parent.relative_to(src)
        renames = RENAMES if Path(dst.name) / rel == ROBOT else {}
        lines = tests_lines(tst, renames)
        ov = overlay / rel / "tst_all.overlay" if overlay else None
        if ov is not None and ov.exists():
            lines += tests_lines(ov, renames)
        (dst / rel / "TESTS").write_text(HEADER.format(name=rel.as_posix())
                                         + "".join(f"{l}\n" for l in lines))
    if overlay is not None and overlay.is_dir():
        for f in sorted(overlay.rglob("*")):
            if f.is_file() and f.name not in ("tst_all.overlay", "PORTING.md"):
                target = dst / f.relative_to(overlay)
                target.parent.mkdir(parents=True, exist_ok=True)
                shutil.copy2(f, target)
    if (dst / "Robot").is_dir():
        rename_robot(dst / "Robot")


def main():
    ov = REPO / "tests" / "legacy-overlay" / "elan3"
    for top in ("applications", "contributions"):
        import_tree(rt.ELAN3 / top, REPO / top, ov / top)
        print(f"import_legacy: {top}/ made")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

def discover(suites=None, apps=None):
    """Tests of the historical tst_all files of the suites (ids relative to
    legacy/) and of the TESTS files of the living copy (spec S9 §8; ids
    relative to the repository, t["copy"] True)."""
    suites = SUITES if suites is None else suites
    apps = APPS if apps is None else apps
    tests, seen = [], set()

    def add(d, lines, rel, copy):
        for cmd, a, long_ in lines:
            if cmd == "jtest":
                if len(a) < 3:
                    continue
                lgi, spc, inp, out, flags = a[0], a[1], None, a[2], a[3:]
            else:
                if len(a) < 4:
                    continue
                lgi, spc, inp, out, flags = a[0], a[1], a[2], a[3], a[4:]
            for kind in KIND_OF_CMD[cmd]:
                tid = f"{rel}::{kind}::{lgi}:{spc}:{inp or '-'}:{out}"
                if tid in seen:
                    continue
                seen.add(tid)
                tests.append(dict(id=tid, dir=d, kind=kind, lgi=lgi, spc=spc,
                                  inp=inp, out=out, flags=flags, long=long_, copy=copy))

    for suite in suites:
        for tst in sorted(suite.rglob("tst_all")):
            if tst.parent != suite:          # top-level driver (tst_one ...)
                add(tst.parent, parse_tst_all(tst), tst.parent.relative_to(ROOT), False)
    for top in apps:
        for tf in sorted(top.rglob("TESTS")):
            add(tf.parent, parse_tests(tf), tf.parent.relative_to(REPO).as_posix(), True)
    return tests

"""Rename the bench ids of the ELAN 3 applications once, when the bench
switched from legacy/elan3 to the living copy (spec S9 §8):

REPO = HERE.parent.parent

import run_tests as rt  # noqa: E402

         REPO / "tests" / "compiler-rs" / "bench_g_expected.tsv",
         REPO / "tests" / "compiler-rs" / "bench_r_expected.tsv"]


def new_id(old):
    if not old.startswith(("elan3/applications/", "elan3/contributions/")):
        return old
    path, kind, fields = old[len("elan3/"):].split("::")
    lgi, spc, inp, out = fields.split(":")
    if path == "applications/Robot":
        lgi, inp, out = (RENAMES.get(w, w) for w in (lgi, inp, out))
    return f"{path}::{kind}::{lgi}:{spc}:{inp}:{out}"


def migrate_file(path):
    lines = path.read_text().splitlines(True)
    out = []
    for line in lines:
        if line.startswith("#") or not line.strip():
            out.append(line)
            continue
        tid, sep, rest = line.partition("\t")
        out.append(new_id(tid) + sep + rest)
    path.write_text("".join(out))


def migrate_snapshots(old_ids):
    moved = 0
    for old in old_ids:
        new = new_id(old)
        src = rt.SNAPDIR / (rt.safe(old) + ".out")
        if new != old and src.exists():
            src.rename(rt.SNAPDIR / (rt.safe(new) + ".out"))
            moved += 1
    return moved


def main():
    old_ids = {line.split("\t")[0] for line in rt.BASELINE.read_text().splitlines()
               if line.strip() and not line.startswith("#")}
    moved = migrate_snapshots(old_ids)
    for f in FILES:
        if f.exists():
            migrate_file(f)
    print(f"migrate_ids: {len(FILES)} files rewritten, {moved} snapshots renamed")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

def plan(tests):
    """One (test to run on the reference, target file) per distinct output
    of the copy's tests that has no .out yet: kind I for itest/aitest
    lines, J for gtest lines."""
    jobs, kinds = [], {}
    for t in tests:
        if not t.get("copy"):
            continue
        kind = "J" if t["kind"] == "G" else "I"
        key = (t["dir"], t["out"])
        if key in kinds:
            if kinds[key] != kind:
                raise SystemExit(f"{t['id']}: output {t['out']} is used by interpreter and "
                                 "compiled lines: give the gtest line its own output name")
            continue
        kinds[key] = kind
        jobs.append((dict(t, kind=kind), rt.samples(t["dir"]) / f"{t['out']}.out"))
    return jobs
